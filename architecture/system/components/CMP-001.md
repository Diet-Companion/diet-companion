responsibilities: 'The Owner''s phone interface as an installable web app (ADR-001 a): sign-in screen (ADR-004 d), photo capture
  and upload, prompts for missing values, and timing of the add flow. It also shows the targets setup before anything else
  while getTargetRanges reports setup_complete false (REQ-009/AC-001), with range fields for calories, protein and fat only
  and no per-day option (AC-007, AC-008), and lets the Owner change a range later. It also has a plan screen (today and the
  next day, REQ-013) and a log screen (REQ-014), each with the five meals: add a product with grams or pieces, or a whole
  dish; change an amount; remove an entry; confirm a meal as planned, shown only for a meal with has_plan true (REQ-014/AC-013);
  log a dish''s products separately with changed amounts (ADR-018). It shows each entry''s product or dish with replaced or
  deleted marks and the structured entry errors, and takes today from the day responses (ADR-016/C-003). It calls only IF-001.'
