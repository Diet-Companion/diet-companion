- key: a
  summary: One developer-focused PaaS vendor hosts the backend container and its managed relational database, with one bill
    and private networking between them.
  satisfies:
  - REQ-003
  - REQ-007
  pros: Fewest moving parts; one account and one invoice; backups come with the managed database.
  cons: Always-on small instances plus a paid database may use much of the $25 ceiling; a new account is needed.
  cost: Not stated by any source; must be checked against the ceiling (A-006).
  reversibility: two-way
  risks: Fixed fees may leave little room for recognition spend.
  constraints:
  - id: ADR-006/C-001
    statement: The monthly total of hosting, database and recognition API spend stays under $25 and is reviewed against the
      provider bills.
    kind: deployment
    check: review
  affects:
  - CMP-002
  consequences: A single vendor holds the app and its data.
  cites:
  - ADR-001
  - ADR-003
  - A-006
- key: b
  summary: A scale-to-zero container service for the backend, with a separate serverless managed relational database that
    has a free or low tier.
  satisfies:
  - REQ-003
  - REQ-007
  pros: Usage-based billing for one user is likely the lowest fixed cost.
  cons: Two vendors and two accounts. Cold starts may slow the add flow (QAS-001). Free tiers may pause or limit the database.
  cost: Not stated by any source (A-006).
  reversibility: two-way
  risks: Cold starts, database pausing and tier changes.
  constraints:
  - id: ADR-006/C-002
    statement: The monthly total of hosting, database and recognition API spend stays under $25, and database tier limits
      and pausing are checked so data cannot be dropped.
    kind: deployment
    check: review
  affects:
  - CMP-002
  consequences: Two vendor accounts and a configured network path between them.
  cites:
  - ADR-001
  - ADR-003
  - QAS-001
  - A-006
- key: c
  summary: 'Google Cloud in the Owner''s existing account: backend container on Cloud Run, database on Cloud SQL for PostgreSQL
    db-f1-micro, single zone. The app is reached at its run.app HTTPS URL.'
  satisfies:
  - REQ-003
  - REQ-007
  - Diet-Companion/diet-companion#37 comment 7126659305
  pros: Existing account; Cloud Run stays stateless (ADR-001/C-002); Cloud SQL is standard managed PostgreSQL, so lock-in
    is limited; mature backups and monitoring.
  cons: Single zone gives no failover. Cloud Run may cold start. Cloud SQL has a fixed monthly fee.
  cost: 'Owner''s estimate (comment 7126659305): Cloud Run within its free tier at this load; Cloud SQL about $8 to $11 a
    month plus storage, from third-party price lists; Claude API about $0.25 a month at 30 photos. The total stays under the
    $25 ceiling. The Cloud SQL figure is unconfirmed in Google''s calculator (A-006, A-007).'
  reversibility: two-way
  risks: Cloud SQL price differs from the third-party list and uses more of the ceiling. A single-zone database can be unavailable
    during maintenance or an outage. Cold starts may lengthen the add flow (QAS-001).
  constraints:
  - id: ADR-006/C-003
    statement: The backend runs on Cloud Run and the database is Cloud SQL for PostgreSQL in the Owner's existing Google Cloud
      account; no other vendor holds app data.
    kind: deployment
    check: review
  - id: ADR-006/C-004
    statement: Automated Cloud SQL backups are enabled, and a restore is tested once before real data is entered.
    kind: data
    check: review
  - id: ADR-006/C-005
    statement: Database connection details and the recognition API key are provided only as platform secrets or configuration.
    kind: technology
    check: review
  - id: ADR-006/C-006
    statement: The monthly total of hosting, database and recognition API spend stays under $25. Cloud SQL's price is confirmed
      in Google's calculator before production, and a billing alert is set below the ceiling.
    kind: deployment
    check: review
  - id: ADR-006/C-007
    statement: The app is served over HTTPS at the Cloud Run run.app URL. A custom domain is added only through a later decision.
    kind: deployment
    check: review
  - id: ADR-006/C-008
    statement: Container configuration sets no minimum instance count unless the Owner decides it, so cost stays at the free
      tier. The cold-start effect on the QAS-001 add-flow measure is observed after the first deployment.
    kind: deployment
    check: review
  affects:
  - CMP-002
  consequences: DevOps configures one Google Cloud project, a Cloud Run service, a Cloud SQL instance and a billing alert.
    The ceiling holds only if A-006 is confirmed.
