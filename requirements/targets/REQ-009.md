# REQ-009: Set and change daily target ranges

**Actor:** Owner. **Need:** Set a minimum and maximum for calories, protein and fat on first use, and change them later. **Value:** Ranges stay current with the diet while past days keep the ranges that applied.

## Scope

In:
- First-use setup, validity of a range, limit values, changing a range from the same day, closed days unaffected by a change. (INT-002#T99/T100, INT-002#T87/T88, INT-002#T7/T8, Diet-Companion/diet-companion#12 comment 7077180098, Diet-Companion/diet-companion#12 comment 7077225554)

Out:
- Other nutrients, such as a later salt range. (INT-002#T59/T60)

## Acceptance criteria

### REQ-009/AC-001 (positive)

Key: daily targets / no target / first use

- **Given** Owner opens the app for the first time
- **Given** No ranges exist
- **When** Owner starts using the app
- **Then** The app asks for the ranges of calories, protein and fat before anything else in the app is available

Cites: INT-002#T99/T100, INT-002#T95/T96

### REQ-009/AC-002 (negative)

Key: daily targets / no target / minimum not above maximum

- **Given** Owner is setting the calories range
- **When** Owner saves a range with minimum 2000 and maximum 1800
- **Then** The range is not saved
- **Then** The previous range stays in force

Cites: INT-002#T87/T88

### REQ-009/AC-003 (negative)

Key: daily targets / no target / both limits required

- **Given** Owner is setting the protein range
- **When** Owner saves a range with a minimum of 80 and no maximum
- **Then** The range is not saved

Cites: INT-002#T91/T92

### REQ-009/AC-004 (boundary)

Key: daily targets / no target / minimum equal to maximum

- **Given** Owner is setting the fat range
- **When** Owner saves a range with minimum 70 and maximum 70
- **Then** The range is saved

Cites: A-002, Diet-Companion/diet-companion#12 comment 7077180098

### REQ-009/AC-005 (positive)

Key: daily targets / no target / effective from

- **Given** The calories range is 1800 to 2200
- **Given** Today is day D and its log total is 2250
- **When** Owner changes the calories range to 1900 to 2300 on day D
- **Then** Day D, including D itself, and later days are compared with 1900 to 2300
- **Then** Day D's calories total 2250 is inside the range

Cites: INT-002#T7/T8

### REQ-009/AC-006 (negative)

Key: daily targets / no target / past days' range

- **Given** Day D-1 was compared with the calories range 1800 to 2200 and its total of 2250 showed red
- **Given** Owner changes the range to 1900 to 2300 on day D
- **When** Owner views day D-1
- **Then** Day D-1 is compared with 1800 to 2200 and still shows red

Cites: INT-002#T11/T12

### REQ-009/AC-007 (negative)

Key: daily targets / no target / variation by day

- **Given** The calories range is 1800 to 2200
- **When** Owner looks for a way to set a different range for a Saturday
- **Then** No day-specific range can be set
- **Then** Saturday is compared with 1800 to 2200 like every other day

Cites: INT-002#T15/T16

### REQ-009/AC-008 (negative)

Key: daily targets / no target / nutrients in current scope

- **Given** Owner is on the targets setup
- **When** Owner looks for a salt range
- **Then** Only calories, protein and fat ranges can be set

Cites: INT-002#T59/T60

### REQ-009/AC-009 (boundary)

Key: daily targets / no target / limit values

- **Given** Owner is setting the calories range
- **When** Owner saves a range with minimum 0 and maximum 2200
- **Then** The range is saved

Cites: A-004, Diet-Companion/diet-companion#12 comment 7077180098

### REQ-009/AC-010 (negative)

Key: daily targets / no target / limit values

- **Given** Owner is setting the calories range
- **When** Owner saves a range with minimum -1 or a decimal limit such as 1800.5
- **Then** The range is not saved
- **Then** The previous range stays in force

Cites: A-004, Diet-Companion/diet-companion#12 comment 7077180098

### REQ-009/AC-011 (negative)

Key: daily targets / no target / change on a closed day

- **Given** Day D is already confirmed as closed with a calories total of 2250 showing red against 1800 to 2200
- **When** Owner changes the calories range to 1900 to 2300 on day D
- **Then** Day D's result stays red against 1800 to 2200
- **Then** Days after D are compared with 1900 to 2300

Cites: INT-002#T67/T68, A-010, Diet-Companion/diet-companion#12 comment 7077225554
