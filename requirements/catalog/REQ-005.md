# REQ-005: Edit, soft-delete and restore products

**Actor:** Owner. **Need:** Change, delete or restore a product without altering past logs and plans. **Value:** History stays accurate.

## Scope

In:
- Changing nutrient values records a new product; the old one is unchanged; past entries keep the old one; next planning uses the new one; the old one cannot be chosen for new planning and logging. (INT-001#T75/T76, INT-001#T79/T80, INT-001#T83/T84, INT-001#T293/T294, Diet-Companion/diet-companion#6 comment 7069241935)
- Changing only name, brand, shop or portion example changes the product in place; a product in the weekly shopping plan stays there and shows the new data. (Diet-Companion/diet-companion#6 comment 7069241935, Diet-Companion/diet-companion#6 comment 7076464547)
- Soft delete: visible in past records, invisible in all new ones; saved dishes unchanged. The Owner can restore a soft-deleted product. (INT-001#T91/T92, INT-001#T95/T96, Diet-Companion/diet-companion#6 comment 7069241935)
- A nutrient edit or soft delete removes the product from the weekly shopping plan; the new product is not added automatically. (INT-001#T297/T298, INT-001#T301/T302)
- An edit or a restore that would give two selectable products the same name and shop is refused; a nutrient edit is not a duplicate, because the earlier version is not selectable. (Diet-Companion/diet-companion#30 comment 7082035557, R-003, R-004)

Out:
- None.
