В T2 вы написали, что натрий считаете как «соль × 400». Как натрий должен

### T16 [human]

Перевод простой: поваренная соль (NaCl) примерно на 39% состоит из натрия,
потому что атомная масса натрия 23, а всей молекулы NaCl 58.4 (23 / 58.4 ≈
0.393). Значит, 1 г соли даёт около 393 мг натрия. Я округляю до 400 для
простоты, получается 1 г соли ≈ 400 мг натрия.

### T17 [interviewer]

topic: T-01 · kind: readback · key: {entity: product, target_id: null, attribute: sodium_mg} · value: натрий (мг) = соль (г) × 400; округление от ≈ 393 мг на 1 г соли · from: T2, T16

- Углеводы, сахара, клетчатка, соль и натрий необязательны; без них продукт сохраняется (INT-001#T13/T14, INT-001#T191/T192)
- Натрий (мг) = соль (г) × 400, округление от ≈ 393 (INT-001#T17/T18, INT-001#T193/T194)
- Натрий вычисляется из соли (INT-001#T277/T278)
- Из заметок хранится только пример пересчёта на порцию; дата фото, кДж, насыщенные жиры, состав и аллергены, срок годности не хранятся (INT-001#T21/T22, INT-001#T195/T196)
- Пример пересчёта на порцию: размер порции в граммах и калории этой порции (INT-001#T281/T282)
- Значения питательных веществ хранятся на 100 г (INT-001#T25/T26, INT-001#T197/T198)
- Значения на 100 мл принимаются как на 100 г (100 мл = 100 г) (INT-001#T29/T30, INT-001#T199/T200)
- Количество продукта в плане и журнале задаётся весом; все продукты взвешиваются (INT-001#T33/T34, INT-001#T201/T202)
- У поштучного продукта при сохранении записывается средний вес одной штуки (INT-001#T55/T56, INT-001#T203/T204)
- У продукта ровно один магазин (INT-001#T37/T38, INT-001#T205/T206)
- Если ту же еду можно купить и в другом магазине, каталог не меняется (INT-001#T41/T42, INT-001#T207/T208)
- Бренд и магазин — два отдельных поля (INT-001#T45/T46, INT-001#T209/T210)
- Магазин обязателен, бренд необязателен (INT-001#T49/T50, INT-001#T211/T212)
- Вес поштучного продукта в блюде = число штук × средний вес штуки из каталога (INT-001#T59/T60, INT-001#T213/T214)
- Блюдо планируют и записывают целой порцией (INT-001#T63/T64, INT-001#T215/T216)
- При отличии от сохранённой порции запись журнала указывает все продукты блюда и их вес или количество (INT-001#T67/T68, INT-001#T217/T218)
- Отличия в записи журнала не меняют блюдо в каталоге (INT-001#T71/T72, INT-001#T219/T220)
- Другое количество продукта блюда в плане дня создаёт новое блюдо (INT-001#T285/T286)
- Изменение значений продукта записывает новый продукт (INT-001#T75/T76, INT-001#T221/T222)
- Старый продукт остаётся в каталоге без изменений (INT-001#T79/T80, INT-001#T223/T224)
- Прошлые записи журнала и прошлые планы дня ссылаются на старый продукт (INT-001#T83/T84, INT-001#T225/T226)
- При следующем планировании используется новый продукт (INT-001#T293/T294)
- Удаление продукта — soft delete (INT-001#T87/T88, INT-001#T227/T228)
- Мягко удалённый продукт виден в прошлых записях и не виден ни в каких новых (INT-001#T91/T92, INT-001#T229/T230)
- Мягкое удаление продукта не меняет блюда, в которые он входит (INT-001#T95/T96, INT-001#T231/T232)
- Изменение состава или количеств блюда создаёт новое блюдо (INT-001#T99/T100, INT-001#T233/T234)
- Прошлые записи ссылаются на старое блюдо, следующее планирование использует новое (INT-001#T105/T106, INT-001#T235/T236)
- Со старым блюдом в каталоге после изменения ничего не происходит (INT-001#T289/T290)
- Удаление блюда — soft delete (INT-001#T109/T110, INT-001#T237/T238)
- Мягко удалённое блюдо видно только в журнале (INT-001#T113/T114, INT-001#T239/T240)
- Изменённый или мягко удалённый продукт удаляется из недельного плана покупок (INT-001#T297/T298)
- Новый продукт после изменения в план покупок не добавляется (INT-001#T301/T302)
- Добавление по фото: пользователь загружает фото, приложение распознаёт и записывает в каталог (INT-001#T117/T118, INT-001#T241/T242)
- Между распознаванием фото и записью пользователь ничего не делает (INT-001#T121/T122, INT-001#T243/T244)
- Магазин берётся с этикетки; если его нет, приложение спрашивает пользователя (INT-001#T125/T126, INT-001#T245/T246)
- Если калории, белок или жир не распознаны, приложение спрашивает пользователя (INT-001#T129/T130, INT-001#T247/T248)
- Название берётся с этикетки; если его нет, приложение спрашивает пользователя (INT-001#T133/T134, INT-001#T249/T250)
- Без этикетки: пользователь даёт название, приложение ищет данные онлайн и заносит продукт в каталог (INT-001#T137/T138, INT-001#T251/T252)
- Между онлайн-поиском и записью участия пользователя нет (INT-001#T141/T142, INT-001#T253/T254)
- У продукта есть поле источника: «этикетка» или «онлайн» (INT-001#T145/T146, INT-001#T255/T256)
- У продукта из онлайн-поиска магазин может иметь значение по умолчанию (INT-001#T149/T150, INT-001#T257/T258)
- Значение магазина по умолчанию — «любой» (INT-001#T305/T306)
- Продукты с магазином «любой» — отдельная группа в недельном плане покупок (INT-001#T309/T310)
- Лист «Этикетки» больше не будет использоваться (INT-001#T155/T156, INT-001#T259/T260)
- Пользователь сам добавит 44 продукта из листа по одному (INT-001#T159/T160, INT-001#T261/T262)

- Для каталога действует 5 минут, а не «seconds» из Vision (INT-001#T317/T318)
- На данном этапе подключение к интернету считается всегда доступным (INT-001#T173/T174, INT-001#T267/T268)
