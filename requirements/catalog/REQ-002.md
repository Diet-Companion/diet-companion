# REQ-002: Product record and validation

**Actor:** Owner. **Need:** Save a product with its nutrient values per 100 g, a brand, exactly one shop and a source. **Value:** Plans, log, targets and shopping can all rely on one consistent product record.

## Scope

In:
- Required: name, shop, calories, protein, fat. Optional: carbohydrate, sugars, fibre, salt, brand, portion example, average piece weight. (INT-001#T9/T10, INT-001#T13/T14, INT-001#T49/T50, Diet-Companion/diet-companion#6 comment 7076484011)
- Sodium (mg) is computed from salt (g) x 400; with no salt value it is 0 mg. (INT-001#T277/T278, INT-001#T17/T18, Diet-Companion/diet-companion#6 comment 7069241935)
- Values stored per 100 g; 100 ml label values taken as per 100 g. (INT-001#T25/T26, INT-001#T29/T30)
- Average piece weight is an optional field on any product; filling it makes the product counted by the piece. (INT-001#T55/T56, Diet-Companion/diet-companion#6 comment 7069241935)
- Portion example stored as portion grams and portion calories. (INT-001#T281/T282)
- Two selectable products may not have the same name and shop; brand is ignored, and letter case and extra spaces don't count. (Diet-Companion/diet-companion#29 comment 7081922823, Diet-Companion/diet-companion#30 comment 7082035557, R-003)

Out:
- Photo date, kJ, saturated fat, ingredients and allergens, expiry date are not stored. (INT-001#T21/T22)
- A second shop for the same product. (INT-001#T37/T38, INT-001#T41/T42)
